# Programacion2-Grupo6-Semana8

## Práctica de GitHub - Programación II

Este repositorio corresponde a la práctica de GitHub de la asignatura Programación II, Semana 8.

## Objetivo

Aplicar el uso de Git y GitHub mediante la creación de ramas, commits, Pull Requests y resolución de conflictos.

## Proyecto

El proyecto consiste en un sistema básico de gestión de clientes desarrollado en Java 21 LTS.

## Estructura del proyecto

- `Cliente.java`: representa la entidad Cliente.
- `Main.java`: contiene el método principal del programa.

## Tecnologías utilizadas

- Java 21 LTS
- Git
- GitHub
- Visual Studio Code

## Flujo de trabajo

Se utilizará una rama principal `main` y ramas de características para desarrollar cambios antes de integrarlos mediante Pull Requests.
